В этом посте, будет описание настройки прокси-сервера [**Dante**](https://www.inet.no/dante/) на **VPS** c **Ubuntu 22.04**.

Предполагается, что на настраиваемой системе, уже настроен доступ по SSH, а так же на VPS используется UFW, в качестве фаервола.

Интересные ссылки: [1](https://www.digitalocean.com/community/tutorials/how-to-set-up-dante-proxy-on-ubuntu-20-04), [2](https://gist.github.com/4faramita/431f92a0fca1b8f0239ac4947ea2122b), [3](https://www.inet.no/dante/doc/1.4.x/config/server.html)

Устанавливаем Dante.
```bash
$ sudo apt install dante-server
```

Создаем новый или раскомментируем следующие строчки в базовом конфиге.
```bash
$ sudo vim /etc/danted.conf
```
```conf
logoutput: syslog
user.privileged: proxy
user.unprivileged: nobody

# wg0 must exists - vpn started
internal: wg0 port = 3128
external: eth0

socksmethod: none
clientmethod: none

client pass {
    from: 192.168.99.0/0 to: 0.0.0.0/0
	log: error
}

socks pass {
    from: 192.168.99.0/0 to: 0.0.0.0/0
	log: error
}
```
Здесь:
<br>`internal: wg0 port = 3128` - это сетевой интерфейс и порт, на которых **Dante** будет висеть (принимать запросы).
<br>`external: eth0` - внешний интерфейс, куда **Dante** будет перекидывать трафик.
<br>`from: 192.168.99.0/0 to: 0.0.0.0/0` - это с какой подсети принимать пакеты и в какую перебрасывать.

Добавляем правило в фаервол.
```bash
$ sudo ufw allow in on wg0 to any port 3128
```

Запускаем сервис Dante.
```bash
$ sudo systemctl start dented.service
```

Готово. 

Если нужен прокси socks5 с аутентификацией, то нужно выполнить следующее:
1. Добавить пользователя, с паролем, но без возможности логина.
```bash
$ sudo adduser --system --no-create-home --disabled-login proxy_auth
$ sudo passwd proxy_auth
```
2. Поменять в конфиге следующие строчки:
```bash
$ sudo vim /etc/danted.conf
```
``` conf
user.privileged: root
socksmethod: username
```

На клиенте, указываем такую строку: `socks://proxy_auth:user_password@192.168.99.1:3128`

*Update 30.12.2024.*
У хостера VPS, поменялись настройки, что-ли, из-за чего **dante** перестал работать. В ходе отладки выяснилось, что при резолве адреса (hostname resolve), в приоритете 
используется IPv6. А **dante**, не настроен на работу с ним. В итоге, проблема решилась так:
```conf
socks pass {
    #from: 192.168.99.0/0 to: 0.0.0.0/0
    from: 192.168.99.0/0 to: 0/0
    log: error
}
```
0/0 разрешает работать как с IPv4 так и с IPv6.

Так же в ходе поиска решения, добавил логов:
```conf
logoutput: syslog stdout /var/log/sockd.log
errorlog: syslog stdout /var/log/sockd_err.log
```
Потом запуска **dante** прямо из шела и смотрел вывод в консоль:
```sh
sudo danted
```

Для проверки запросов, использовал **curl**:
```sh
curl --socks5 192.168.88.1:3128 ifconfig.me/all -v
```
